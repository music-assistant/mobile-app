# Navigation

The app has a bottom bar and a side menu. Use them to go to the screens of the app.

## The bottom bar

On a phone, the bottom bar has these buttons:

| Button | Description |
|---|---|
| **Menu** | Opens the side menu. |
| **Discover** | Opens the [Discover](home.md) page. |
| **Search** | Opens the [Search](global-search.md) page. |
| Selected player | Shows the name of the selected player. Tap it to select a different player. |

Tap **Discover** or **Search** again to go back to the top of that page.

## The side menu

The side menu has three sections:

| Section | Entries |
|---|---|
| **Explore** | **Discover**, **Search** and **Browse**. |
| **Library** | One entry for each library category: **Artists**, **Albums**, **Tracks**, **Playlists**, **Audiobooks**, **Podcasts**, **Radio**, **Genres** and **AI Radio**. |
| **System** | **Party** and **Settings**. |

Tap an entry to open its page. For more information, see [Library](library.md).

Some entries show only if the server has the related plugin:

- **AI Radio** shows only if the server has the AI Radio plugin. See [AI Radio](ai-radio.md).
- **Party** shows only if the server has the Party plugin. See [Party](party.md).

On a wide screen, for example a tablet in landscape, the side menu shows at all times. The app then shows no bottom bar.

## Customizing the side menu

1. Open the side menu.
2. Tap the **pencil icon** next to the app name.
3. Clear the checkbox of each entry that you want to hide.
4. In the **Library** section, drag an entry by its handle to move it.
5. Tap the **done icon** to save the changes.

Only the entries of the **Library** section move. You can hide **Browse** and **Party**, but you cannot move them. You cannot hide **Discover**, **Search** or **Settings**.

The app saves the changes on this device only.
