# AI Radio

**AI Radio** lists the AI radio stations of your Music Assistant server. You create and edit the stations in the Music Assistant web app. The app lists them and plays them.

**AI Radio** shows in the **Library** section of the side menu only if all of these conditions are true:

- The server has the AI Radio plugin.
- The server schema is 88 or later. The **Settings** screen shows the schema of your server.
- Your user has permission to use the AI radio stations.

## Playing a Station

1. Select a player.
2. Open the side menu, then tap **AI Radio**.
3. Tap the **play icon** of a station.

The station plays on the selected player. To stop it, use the player controls.

If no player is selected, the screen shows "Select a player first". If the server has no stations, the screen shows "No AI stations yet. Create one in the Music Assistant web app."

The **Radio** list of your library does not show the AI radio stations, because **AI Radio** lists them.
