# Party

The Party plugin of Music Assistant lets guests add songs to one queue. The guests use the web page of the party. The app shows the host side: the invite and the party settings.

**Party** shows in the **System** section of the side menu only if the server has the Party plugin.

## Inviting Guests

1. Open the side menu, then tap **Party**.
2. Let your guests scan the QR code.

To send the link instead, tap **Copy link**. Then paste the link into a message.

If guest access is off, the sheet shows no QR code.

## Party Settings

The party settings show only if your user has permission to change the provider settings on the server. Other users see only the invite.

> **Caution:** If you turn off guest access, all guests lose access to the party.

The guest access switch turns the party on or off. The app saves the change immediately.

While the party is off, set up the party first. Then turn on guest access. The app saves your changes and starts the party.

While the party is on, the QR code shows first. Tap **Party settings** to show the settings. Change the settings, then tap **Save**.

The server gives the names of the settings.
